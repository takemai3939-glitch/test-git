# 日本株需給モニター

VIX・ドル円・日経先物など12指標を統合し、今日の日本株の地合いを **0〜100点** でスコア化する判定ツールです。登録不要・無料で、毎朝30秒で相場の需給環境を可視化します。

## デモ

[https://takemai3939-glitch.github.io/test-git/](https://takemai3939-glitch.github.io/test-git/)

## 使用技術

| 技術 | 用途 |
|------|------|
| HTML5 | マークアップ・フォーム構造 |
| CSS3 | ダークテーマUI・レスポンシブ対応・SVGアニメーション |
| JavaScript (Vanilla) | スコア計算・DOM操作・localStorage管理 |
| Canvas API | スコア推移チャート描画 |
| localStorage | 入力履歴・前回値の永続化 |

外部ライブラリ・APIキー・サーバーサイド処理は一切不要です。

## 機能一覧

### 入力指標（12指標）

**外部環境**
- VIX（米国恐怖指数）
- ドル円
- 米10年金利
- NASDAQ騰落率
- S&P500騰落率
- 日経先物（前日比%）

**内部指標**
- 値上がり銘柄数 / 値下がり銘柄数（→騰落比率を自動計算）
- 売買代金（兆円）
- 空売り比率
- 騰落レシオ（25日）
- 信用評価損益率
- 海外投資家フロー（億円）

**イベント・ニュース**
- 日銀イベント / FOMC・CPI等（各 -5点ペナルティ）
- ニュースメモ・トランプ/地政学メモ（14キーワードを自動検出）

### 判定結果

- **需給スコア**（0〜100点）＋ SVGリングアニメーション
- **判定ラベル**：かなり強い / 強め / 中立 / 弱め / かなり弱い
- 寄り前警戒度・地合い分類（リスクオン/中立/リスクオフ）
- 朝の地合いメモ（自動生成コメント）
- 指標別寄与度バー
- 検出キーワードタグ

### その他の機能

- **前回値復元**：最後に判定した入力値をワンクリックで復元
- **履歴機能**：判定結果を最大30件 localStorage に自動保存
- **スコア推移チャート**：Canvas でスコアの変化をグラフ表示
- **2件比較**：履歴から2件を選択して指標を並べて比較
- **モバイル対応**：スティッキー判定バー・タッチ最適化UI

## ローカルでの実行方法

サーバー不要です。`index.html` をブラウザで直接開くだけで動作します。

```bash
git clone https://github.com/takemai3939-glitch/test-git.git
cd test-git
# index.html をブラウザで開く（ダブルクリック or ドラッグ&ドロップ）
```

Chrome / Edge / Safari / Firefox の最新版で動作確認済みです。
